# Cardiac Digital Twin sample

This sample is sourced from the public
[`samueltauil/cardiac-digital-twin`](https://github.com/samueltauil/cardiac-digital-twin)
repository at commit `b660962358a4fa19ab0aea059e96c9bba23ffa6c`.

## Scenario

The pair models the project README's demonstration scenario:

> increase the beta-blocker dose by 20%, from 50 mg to 60 mg.

The architecture includes:

```text
BetaBlockerDose
  -> BetaBlockerPK
  -> HeartRateModel (Hill/Emax + baroreflex correction)
  -> CardiacOutputModel
  -> BloodPressureModel
  -> BaroreflexController
       └── feedback to HeartRateModel
```

The sample is useful for demonstrating structural and parameter drift:

- the dose parameter changes from `50` to `60`;
- the target snapshot records the closed-loop baroreflex path;
- physiology-facing configuration values and outputs are retained as evidence;
- the visual canvas presents the changed blocks and connections instead of a
  generic three-row fixture.

## Provenance and limits

The upstream `.slx` is generated by `source/create_cardiac_model.m` and is
ignored by the upstream repository. No binary model was silently fabricated or
copied into this repository. The JSON snapshots are canonical sample
manifests derived from the public builder source and are marked `partial`
until a licensed MATLAB/Simulink extractor produces a complete manifest.

The copied MATLAB source remains under the upstream repository's MIT license.
This repository's sample metadata and manifests are MIT-licensed with the
project.

## Use

```bash
simulink-model-drift compare \
  --base samples/cardiac-digital-twin/baseline.model.json \
  --target samples/cardiac-digital-twin/dose-60mg.model.json \
  --rules examples/rules/default-rules.yml \
  --output build/cardiac-digital-twin \
  --fail-on none
```

Open `samples/cardiac-digital-twin/drift.json` directly in the Copilot canvas
for a precomputed visual review.
